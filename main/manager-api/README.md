# Project Overview

manager-api is built on the Spring Boot framework.

When importing the project into your code editor, select the `manager-api` folder as the project directory.

# Development Environment
JDK 21
Maven 3.8+
MySQL 8.0+
Redis 5.0+
Vue 3.x

# API Documentation
